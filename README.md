# 하랑 이웃 매니저

네이버 블로그 이웃 관리를 돕는 Windows 프로그램의 공식 배포 저장소입니다.

[최신 버전 다운로드](https://github.com/jty0221-dot/harang-neighbor/releases/latest)

ZIP을 내려받아 압축을 풀고 EXE를 실행하세요. 기존 사용자는 프로그램을 종료한 뒤 실행 파일을 교체하고, EXE 옆 data 폴더는 그대로 보존하세요.

설정의 새 판 확인에서 최신 버전과 다운로드 주소를 확인할 수 있습니다. 0.1.1에서 0.2.0으로 처음 올릴 때는 위 다운로드 페이지를 이용하세요.

## 공개 파일

각 릴리스에는 고객용 EXE, 고객용 ZIP, version.json, SHA256SUMS.txt만 포함됩니다. 소스 코드, 고객 계정과 브라우저 프로필, 판매자용 발급 도구는 포함하지 않습니다.

자동 설치는 하지 않으며, 추가 인증은 사용자가 직접 완료해야 합니다.
